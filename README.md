# Automotores Andina · Nueva experiencia

Rediseño conceptual independiente inspirado en una galería de producto oscura. Vue 3, TypeScript y Vite; componentes TA, módulos por caso de uso y composables tipados.

## Desarrollo

```sh
npm install
npm run dev
npm run build
npm test
```

## Contenido

Conserva las rutas públicas, 106 vehículos, fichas, fotografías originales, sedes, equipo, entregas, servicios, aliados, preguntas y documentos legales de [Automotores Andina](https://www.automotoresandina.com.co/). Procedencia en `src/data/provenance.json`.

El inventario es una copia de consulta del 29 de octubre de 2026, sin sincronización automática. Las portadas están optimizadas localmente; las galerías mantienen los enlaces originales. Precios y disponibilidad se confirman con el concesionario. Los favoritos se guardan en el navegador. El formulario de venta prepara un mensaje para el WhatsApp oficial y la financiación dirige al proveedor original; esta versión no incorpora un backend de clientes ni simula envíos.

## Publicación

Compilación estática a `dist/`, con rutas de Vue Router configuradas en `vercel.json`. Proyecto conceptual de portfolio, sin afiliación contractual implícita ni reemplazo del sitio oficial. Marcas, fotografías y contenido comercial pertenecen a sus respectivos titulares.
